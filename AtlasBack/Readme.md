# AtlasLearn — API

Express + TypeScript + Prisma (MongoDB) + Socket.IO. Setup and configuration: [main README](../README.md#getting-started).

| Script | Description |
|---|---|
| `npm run dev` | Development server with reload (http://localhost:3001, Swagger at `/api-docs`) |
| `npm run seed` | Demo accounts and a demo course |
| `npm run build` / `npm run start:prod` | Compile to `dist/` and run it |
| `npm run typecheck` | Type check without emitting |
